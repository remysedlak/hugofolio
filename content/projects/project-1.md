Digital audio workstation built fully in Rust. This started as a solo learning project but I invite everyone to try it out or work on it.

## What it does

- Utilizes custom graphics rendering logic via wgpu
- Handles thread communication with lock free command system
- Built for speed and customizablity

## Why it's interesting

I have been using FL Studio for years and have ran into issues such as corrupted projects, a lack of customization, and a recent abundance of promotional features. I believe creative tools should be free for everyone and started this project as a learning project to see whats going on under the hood of modern DAWs.
