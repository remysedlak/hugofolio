AI anxiety prediction system trained on student mental health data. TensorFlow.js runs in-browser to ensure privacy and data protection.

## What it does

- ML model trained on a Kaggle dataset of student mental health data  
- Predicts future anxiety based on current habits/quantitive data
- Contains supportive features like goal tracking and digital pet

## Why it's interesting

This app utilizes a lightweight in-browser ML model that can run offline. Built in 24 hours, the website contains features to support the user's journey to feel better.
